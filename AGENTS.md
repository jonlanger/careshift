# Design decision log

This project keeps a running design-decision log at [docs/design-log.md](docs/design-log.md) — it's the source material for a portfolio case study, so treat entries as write-once history, not scratch notes.

Whenever you make or change a UX/interaction-design decision (not just implement a spec someone else fully decided), add an entry: **Problem → Decision → Why → Trade-off considered**, plus an **Evidence** line with sources if the decision leans on outside research. Keep entries newest-first. Do this without being asked — it's expected as part of finishing the work, the same way tests are.
